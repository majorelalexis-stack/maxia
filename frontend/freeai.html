FreeIA Gateway

Un agrégateur de LLMs 100% gratuits avec fallback automatique, API compatible OpenAI et mémoire longue durée. Installe-le chez toi en 5 minutes.

✓ Zéro coût ✓ Open source 4 providers Compatible OpenAI Python · FastAPI
💻 Voir sur GitHub Guide d'installation
C'est quoi
Un cerveau IA gratuit sur ton PC
FreeIA Gateway route tes requêtes vers les meilleurs LLMs gratuits disponibles. Si l'un est limité ou en erreur, il bascule automatiquement sur le suivant — sans interruption.

Tu obtiens une API locale compatible avec n'importe quel outil qui supporte OpenAI (AnythingLLM, LibreChat, OpenCode...). Les modèles ont une mémoire partagée entre les conversations grâce à MemPalace.

Fonctionnalités
Tout ce qu'il te faut
Conçu pour fonctionner localement, sans abonnement, sans VPS.
⚡
Fallback automatique
Gemini → Groq → Mistral → HuggingFace. Si un provider renvoie une erreur 429 ou échoue, le suivant prend le relais en silence.
📈
Quota manager
Suivi des requêtes et tokens par provider en SQLite. Reset daily automatique. Tu ne dépasses jamais les limites gratuites.
🔗
API compatible OpenAI
Endpoint /v1/chat/completions avec streaming SSE. Branchez n'importe quel outil qui supporte un endpoint OpenAI custom.
🧠
Mémoire longue durée
MemPalace stocke les souvenirs importants entre sessions. 96.6% de précision, 170 tokens au démarrage, zéro appel API supplémentaire.
📄
RAG intégré
Compatible AnythingLLM. Uploade tes documents, interroge-les avec tes LLMs gratuits. Aucun abonnement cloud nécessaire.
🔐
100% local
Rien ne passe par nos serveurs. Tes données restent chez toi. Seules les requêtes vers les APIs publiques gratuites sortent de ton réseau.

Installation
Prêt en 5 minutes
Prérequis : Python 3.12, AnythingLLM installé.
1
Cloner le repo et installer les dépendances
Télécharge le code et installe les librairies Python nécessaires.
git clone https://github.com/MAXIAWORLD/freeai-gateway cd freeai-gateway pip install -r requirements.txt
2
Configurer tes clés API
Copie le fichier exemple et remplis tes 4 clés gratuites.
cp .env.example .env # Édite .env et remplis : GEMINI_API_KEY=ta_clé_gemini GROQ_API_KEY=ta_clé_groq MISTRAL_API_KEY=ta_clé_mistral HUGGINGFACE_API_KEY=ta_clé_hf
3
Lancer l'API
L'API démarre sur http://localhost:8000. À relancer à chaque démarrage.
python -m uvicorn api:app --port 8000
4
Connecter AnythingLLM
Dans AnythingLLM : Settings → Préférence LLM → Generic OpenAI
Base URL : http://localhost:8000/v1 API Key : freeai (n'importe quoi) Model : freeai-gateway
5
Installer la mémoire longue durée (optionnel)
MemPalace donne une mémoire persistante entre les conversations.
pip install mempalace mempalace init . mempalace mine .
Stack technique
Simple, robuste, extensible
Tout en Python. Aucune dépendance cloud. Fonctionne hors ligne dès que les clés sont configurées.
✓
FastAPI + Uvicorn — serveur ASGI léger, streaming SSE natif, format OpenAI respecté à la lettre
✓
LiteLLM — abstraction universelle qui parle à Gemini, Groq, Mistral et HuggingFace avec la même interface
✓
SQLite — quota manager local, historique de conversations, reset daily automatique sans serveur externe
✓
MemPalace 3.3.3 — mémoire sémantique locale, 170 tokens au démarrage, 29 outils MCP, zéro appel API
✓
29 tests pytest — couverture complète, TDD, tous verts avant chaque release
✓
Compatible AnythingLLM — chat, RAG sur documents, agents, tout fonctionne avec le gateway comme backend LLM
